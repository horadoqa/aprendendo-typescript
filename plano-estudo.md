# Plano de estudos para aprender TypeScript do zero ao avançado

Preparei um roteiro de 8 semanas, com foco em aprender TypeScript na prática, construir projetos reais e desenvolver uma boa base para trabalhar profissionalmente com a linguagem.

## 1. Cronograma de estudos

What is TypeScript?

Semana 1 — Fundamentos

- O que é TypeScript e por que utilizar.
- Diferenças entre JavaScript e TypeScript.
- Instalação do Node.js e TypeScript.
- Tipos primitivos: `string`, `number`, `boolean`.
- Inferência de tipos.
- Arrays e objetos.

Projeto: Cadastro de usuários

TypeScript Functions - Python Guides

Semana 2 — Funções e tipagem

- Tipagem de parâmetros e retornos.
- Parâmetros opcionais.
- Funções anônimas e arrow functions.
- Type aliases (`type`).
- Interfaces (`interface`).
- Union types.

Projeto: Calculadora tipada

Object-Oriented Programming Using TypeScript. | by Youssef Zidan | Medium

Semana 3 — Recursos intermediários

- Enums.
- Tuplas.
- Literal types.
- Intersection types.
- Narrowing.
- Type assertions.
- Null e undefined.

Projeto: Sistema de tarefas

Why TypeScript Generics Matter for Reusability and Safety | Marcus Dantas posted on the topic | LinkedIn

Semana 4 — TypeScript avançado

- Generics.
- Utility types.
- `keyof` e `typeof`.
- Conditional types.
- Mapped types.
- Tipos genéricos reutilizáveis.

Projeto: Biblioteca de funções genéricas

Node.js SaaS Boilerplate with React and MERN stack - Modern MERN

Semana 5 — TypeScript com JavaScript moderno

- ES6+.
- Modules e imports.
- Async/Await.
- Promises.
- Tratamento de erros.
- Consumo de APIs com Fetch.

Projeto: Aplicação que consome uma API

React.js with typescript | SJ Innovation LLC

Semana 6 — TypeScript no desenvolvimento web

- TypeScript com React.
- Tipagem de Props.
- Tipagem de States.
- Hooks com TypeScript.
- Eventos e formulários.
- Componentes reutilizáveis.

Projeto: Dashboard com React

Node.js Full Stack Tutorial: Build Your First App | FreeAPIHub

Semana 7 — Backend com TypeScript

- Node.js com TypeScript.
- Express.
- Controllers e Services.
- DTOs.
- Validação de dados.
- Organização de projetos.

Projeto: API REST com TypeScript

Complete PyTorch Image Classification Pipeline: Transfer Learning, Data Preprocessing, and Production Deployment Guide

Semana 8 — Qualidade e projeto final

- Configuração do `tsconfig.json`.
- ESLint e Prettier.
- Testes automatizados.
- Debugging.
- Boas práticas.
- Arquitetura e organização de código.

Projeto final: Sistema completo tipado
